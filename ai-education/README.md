# AI教育聊天系统

基于FastAPI + LangChain + MySQL的智能聊天系统，支持历史对话管理。

## 功能特性

- 🤖 智能AI对话
- 💾 历史对话保存（MySQL）
- 🔄 对话线程管理
- 📝 消息持久化存储
- ⚡ FastAPI高性能后端

## 技术栈

- **后端框架**: FastAPI
- **AI框架**: LangChain + LangGraph
- **数据库**: MySQL + SQLAlchemy + PostgreSQL（用于checkpoint本地持久化）
- **缓存**: Redis（计划中）
- **部署**: Docker（计划中）
